如果你的实物线是按 WIRING.md 接的，上电后的信号错位是：

补充：CCU60 通道在 P02 上的合法复用（已查 iLLD IfxCcu6_PinMap）：CC60=P02.0、COUT60=P02.1、CC61=P02.7（或 P02.2）、COUT61=P02.3、CC62=P02.4、COUT62=P02.5，全部为 alt7。代码选用的 6 个脚合法；P02.6 不在 CCU60 输出列中，作 GPIO 使能脚也合法。两套方案只能二选一。

5. DRV8305 寄存器配置解析（对照民用版 datasheet，BOOSTXL-DRV8305EVM）

0x07 ← 0x0FF Gate Drive Control

D9 COMM_OPTION=0D8:7 PWM_MODE=11 → 6 路独立 D6:4 DEAD_TIME=111 → 5280nsD3:2 TBLANK=11 → 7µsD1:0 TVDS=11 → 7µs

PWM_MODE=11 与 6 路互补代码匹配；但把死区/blank/deglitch 全部拉到最大档，属于「为压过流先全拉满」的调试态。COMM_OPTION=0 选二极管续流（默认 1 为主动续流）。

0x0C ← 0x01F VDS Sense Control 值非法

D7:3 VDS_LEVEL=00011=3D2:0 VDS_MODE=111（保留值）

VDS_MODE 合法值只有 000 锁存关断 / 001 仅上报 / 010 禁用。写 111 的行为未定义，不能实现「关过流」的意图。要禁用应写 0x012（LEVEL=0,MODE=010），仅上报写 0x001。

缺失的三个动作

  • 写寄存器早于 EN_GATE 拉高：EVM 软件明确要求 enable system 后才允许 SPI 访问，且 PVDD 上电后 tSPI_READY 最长 10ms；
  • 没有 CLR_FLTS：0x09 的 D0 写 1 清锁存故障；
  • 没有喂狗：DRV8305 内置 SPI 看门狗，读 0x01 可喂狗，初始化后再无 SPI 访问，配置可能被周期性复位（请核对 0x09 WD_EN 默认值）。

README 里「配 3 路模式写寄存器 0x06 bit8:7=01」是 Q1 版（SLVSD12）的地址；民用版 DRV8305（SLVSCP2，EVM 所用）PWM_MODE 在 0x07。你代码里的 0x07 地址反而是对的。

7. 模块就绪状态与建议推进顺序

模块状态说明
FOC_PWM (CCU60)需修6 路互补 20kHz 已能输出；引脚映射与接线表冲突（H1）、初始化顺序（M2）、死区（M1）待修。
FOC_DRV8305 (bit-bang SPI)未通过读校验从未通过；采样沿（H3）、访问时序/清故障/喂狗（H4）、0x0C 非法值（H2）。

FOC_ADC (VADC G4)未启用通道号正确，缺 setScan（M4）与零偏标定。
FOC_Algorithm未启用公式正确，SVPWM 待单测，PID 待规范化（L2）。
Cpu1 / Cpu2空闲仅同步后空转，当前全部负载在 Cpu0。

建议顺序（每步都有可观测判据）

  • ① 统一引脚（H1）：先断电核对实物线，确定方案 A/B；示波器确认 EN_GATE 为干净直流高电平、六路 INH/INL 与 CCU6 通道一一对应。
  • ② 修 DRV8305 通信（H3/H4/H2）：EN_GATE 使能后再通信 → 改采样沿 → CLR_FLTS → 读 0x01/0x02 应返回 0 或可解释状态 → 写 0x0C=0x001（仅上报）→ 回读 0x07/0x0C 校验。
  • ③ 收敛死区（M1/M2）：按 M2 调整初始化顺序，MCU 死区 ≤0.5µs、片内死区默认；此时再跑当前开环正弦，电机应平稳慢转（约 20–30rpm 量级），nFAULT 不触发。
  • ④ 电流环前置：补 ADC setScan + 零偏标定，手转电机/加小占空比确认三相电流波形为正弦且和为零。
  • ⑤ 编码器：修 parity，读 ANGLECOM，手动转一圈核对 0→16384 单调性与电角度方向。
  • ⑥ 闭环 FOC：Clarke/Park → Id=0、Iq 电流环 → SVPWM，最后加速度环。
