## PWM 驱动信号 (TC275 → DRV8305)

**当前为 3 路 PWM 接线：只接 INH_A / INH_B / INH_C，INL_A/B/C 悬空（DRV8305 3xPWM 模式）。**

| 信号 | TC275 引脚 | DRV8305 引脚 | 状态 | 说明 |
|------|-----------|-------------|------|------|
| INH_A (上桥A) | P02.0 | INHA | ✅ 已接 | CCU60 CC60 输出 |
| INH_B (上桥B) | P02.7 | INHB | ✅ 已接 | CCU60 CC61 输出 |
| INH_C (上桥C) | P02.4 | INHC | ✅ 已接 | CCU60 CC62 输出 |
| INL_A (下桥A) | P02.1 | INLA | ⚪ 悬空 | 3xPWM 模式芯片内部生成互补下桥 |
| INL_B (下桥B) | P02.3 | INLB | ⚪ 悬空 | 同上 |
| INL_C (下桥C) | P02.5 | INLC | ⚪ 悬空 | 同上 |
| EN_GATE | 3.3V | EN_GATE | ✅ 硬件直连 | 常使能，不占 GPIO |

> ⚠️ **3xPWM 模式要求**：DRV8305 已通过 SPI 配置 reg 0x07=0x2E6（3xPWM，死区 3520ns）。若处于默认 6xPWM 模式，INL 悬空=低电平，bootstrap 无法充电，上桥驱动失效。

## SPI 配置 DRV8305 (GPIO 模拟软件SPI) ✅ 已验证

| 信号 | TC275 引脚 | DRV8305 引脚 | 说明 |
|------|-----------|-------------|------|
| SCLK | P00.0 | SCLK | SPI时钟，CPOL=0空闲低 |
| SDI (MOSI) | P00.1 | SDI | 主机输出/从机输入 |
| SCS (nSCS) | P00.2 | nSCS | 片选，空闲高，拉低有效 |
| SDO (MISO) | P33.0 | SDO | 主机输入/从机输出 |
| nSLEEP | — | NSLT | 驱动板默认拉高（未飞线） |

> SPI 帧格式：16bit，bit15=R/W(0写1读)，bit14~11=地址(4bit)，bit10~0=数据(11bit)，MSB 先传。
> 写：`DRV8305_WriteReg(0x07,0x2E6)` → 3xPWM；`0x0C=0x001F`；`0x09=0x022` 清故障。读回自检通过（LED 常亮）。

## 电流采样 ADC (DRV8305 → TC275) ✅ 已验证

| 信号 | TC275 引脚 | ADC通道 | 说明 |
|------|-----------|---------|------|
| ISEN_A | P40.9 | Group4 Ch7 (AN39) | A相电流采样（固定采样 A/B，C 相 ic=-(ia+ib)） |
| ISEN_B | P40.8 | Group4 Ch6 (AN38) | B相电流采样 |
| ISEN_C | P40.7 | Group4 Ch5 (AN37) | C相电流采样（未直接读） |

> DRV8305 内置 3 路分流放大器，增益 10V/V，采样电阻 7mΩ → `ADC_CURRENT_SCALE = 3.3/4095/10/0.007`。
> 20kHz PWM ISR 内软件触发同步扫描（固定采样点）。零偏典型值 A≈2045、B≈2040、C≈2038。

## 电位器旋钮（调速）✅ 本轮新增

| 信号 | TC275 引脚 | ADC通道 | 说明 |
|------|-----------|---------|------|
| POT（板载旋钮） | **AN0 = 引脚67** | **Group0 Ch0** | 电位器分压 0~3.3V → 12bit |

> **关键：电位器 AN0 是纯模拟输入**——数据手册引脚表无端口控制器（iLLD `IfxVadc_G0_0_AN0_IN = {NULL_PTR,0}`），**无需 GPIO 端口配置**。
> 软件只需 `groupId=IfxVadc_GroupId_0, channelId=IfxVadc_ChannelId_0`，后台自动连续扫描（autoscan）。
> ⚠️ 曾误配为 Group4 Ch0（AN32/P40.4）——那是电流采样组，非电位器，已修正。
> 映射：raw 0~4095 → `g_speed_ref` 0 ~ **-12 rad/s（逆时针）**，raw<40 死区停转，一阶低通防跳变。

## 编码器 SPI (硬件QSPI1) ✅ 已验证

| 信号 | TC275 引脚 | AS5047P 引脚 | 说明 |
|------|-----------|-------------|------|
| SCLK | P10.2 | CLK | QSPI1 SCLK |
| MOSI | P10.3 | MOSI | QSPI1 MTSR |
| MISO | P10.1 | MISO | QSPI1 MRSTA |
| CSn | P10.0 | CS | QSPI1 SLSO10 |

> 14bit 磁编码器，16384 CPR，Mode1 5MHz。主循环读单帧 + 坏帧过滤（delta > ±4096 丢弃）。
> 零位：预定位强拉转子后 100 次读均值（每次上电零偏不同，属正常，无漂移）。

## 串口打印字段语义

| 字段 | 含义 |
|------|------|
| md | FOC 状态机：0=预定位，1=开环加速(I/f)，2=闭环 |
| ang | 电角度×1000（rad） |
| id/iq | 实测 d/q 电流（ADC 码，2048 中心） |
| vd/vq | d/q 轴电压（×1000） |
| ra/rb | A/B 相 ADC 原始码 |
| spd | 实测机械角速度×100（rad/s） |
| iqr | 速度环输出的 iq 给定 |
| sref | 旋钮给定目标转速×100（机械 rad/s，负=逆时针） |
| pot | 电位器 ADC 原始值（12bit） |
| SW th/el | 切换瞬间 θ_i / 电角度（×1000），差<0.3 即切换对齐 |
