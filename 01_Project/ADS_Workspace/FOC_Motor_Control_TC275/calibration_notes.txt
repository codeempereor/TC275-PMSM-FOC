【AS5047P 通信修复记录 (2026-09-29)】
  原问题: 读角度一直 busy/读不到数
  根因1: 命令帧漏算 bit15 偶校验 (PARD)。AS5047P 命令帧 bit15 必须对
         bit14:0 做偶校验，校验失败会在返回帧 EF 位置 1 并拒绝读。
         原代码发 0x7FFF，正确应为 0xFFFF (读 0x3FFF 时)。
  根因2: SPI 模式未显式配置。AS5047P 是 Mode 1 (CPOL=0, CPHA=1)，
         iLLD 默认是 Mode 0，采样沿错位。
  根因3: chCfg.mode 误设为 IfxQspi_SpiMaster_Mode_long，但没调
         packLongModeBuffer，BACON 配置错误。改回默认 short mode。
  修复: FOC_SPI.c 重写
    - as5047p_make_read_cmd() 自动计算偶校验
    - 显式设置 clockPolarity=idleLow, shiftClock=TrailingEdge (Mode 1)
    - dataWidth=16, MSB first, CS 低有效
    - 删除 FOC_Encoder.c/.h (GPIO 模拟版, Mode3 假设错误, 死代码)
    - 主循环每 500ms 调 FOC_SPI_DumpDebug() 打印 frame/EF/PARD/angle
  根因4 (2026-09-29 二次修复): exchange 是异步的, onTransfer 标志靠 QSPI
    TX/RX/Error 三个中断 ISR 清除。原来完全没配中断, 第一次 exchange 后
    onTransfer 永远=1, 第二次 getStatus 死等 busy -> 主循环卡死, 串口停在
    "Turn motor by hand..." 没有 ENC 输出。
    修复: 在 FOC_SPI_Init 里配 QSPI1_TX=4/RX=5/ER=6 中断 (CPU0), 写三个
    IFX_INTERRUPT 调 IfxQspi_SpiMaster_isrTransmit/Receive/Error。
  验证标准:
    - 手转电机, angle 应在 0..16383 间单调变化、回绕正确
    - EF 必须恒为 0; 若 EF=1 说明命令帧仍有错
    - 若 frame 恒为 0x0000/0xFFFF, 查硬件接线 (CS/SCLK/MOSI/MISO)

【闭环转动验证记录 (2026-10-02) — 成功】
  最终配置组合:
    CURRENT_DIR_A/B/C = +1, MOTOR_DIR = +1
    Park 角度取反: sin_e = -sinf(g_elec_angle), cos_e = cosf(g_elec_angle)
    极对数 = 10, 固定采样 A/B, duty 限幅 [0.05, 0.45]
    iq_ref = -50 (顺时针, 实测确认) / +50 (逆时针)
  实测现象:
    复位后电流环启动: 电机滋滋响, 转子静止 (启动死区, 静止力矩不足以克服静摩擦)
    手动拨一下转子 -> 持续顺时针转动 (ang 持续单向单调变化)
    捏住转子 (堵转) -> 停; 再拨一下 -> 再次转起
  结论:
    电流环闭环转动达成 ✓ (方向正确, 力矩能持续驱动)
    遗留问题: 启动死区 — 静止时需外力打破才能启动
    下一步: 解决启动 (I/f 开环启动 或 预定位+强制旋转), 然后加速度环双闭环

【I/f 开环启动成功 (2026-10-02) — 自启动达成】
  实现: 伺服标准 I/f 启动
    阶段0 预定位: θ_i=0, id 斜坡 0→200 (2.3A), 300ms → 转子吸在 α 轴
    阶段1 开环加速: θ_i 自累加, 电频率 2→60 rad/s 斜坡 (0.6s), iq=0 → 电流矢量拖着转子转
    阶段2 闭环切换: ω=60 且 |θ_i-θ_enc|<0.3rad → Park 切编码器角度, id=0, iq=-50
  实测: 上电后电机自行启动转动, 无需手拨 ✓ (串口 md: 0→1→2)
  状态: 电流环闭环 + I/f 自启动 全部达成
  下一步: 速度环 (目标转速→iq_ref) → 双闭环
